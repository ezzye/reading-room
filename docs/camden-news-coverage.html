Search, URL and fuzzy matching

URL candidate bypasses paid search; exact-ish original query then stopword-reduced fallback, 4–200 headline characters, publisher domain restriction, up to 8 results, 30 searches/room/day. Search results never prove readability.

Normalized token overlap (not semantic fuzzy search), score >=0.72 and runner-up gap >=0.12, date penalty 0.35; NewsBank document URL validation. Times/London Telegraph publication checks in HTTP adapter. This is a bounded lexical match, so paraphrases and spelling errors are not guaranteed to work.

Seven synthetic matching checks passed: exact headline, punctuation and minor word variants accepted; unrelated headline, equal best matches, conflicting date and foreign result URL rejected. These checks do not test Camden login or actual source retrieval.

Next implementation checks

  1. Authenticate ordinary Camden NewsBank title browser and record source IDs, coverage dates, formats and current availability before enabling any additional library title.
  2. Prioritise Guardian/Independent/Standard existing public adapters; extend explicit NewsBank publication source mapping for each title only after observed entitlement.
  3. Treat Observer current domain and archive identities separately; never silently alias it to Guardian.
  4. For Financial Times record current embargo/availability from authenticated source information; do not infer same-day from daily collection refresh.
  5. Add Mail/Mirror/Sun dedicated public profiles only after bounded official-page fixtures and source-boundary checks.
  6. For magazines verify Camden issue entitlement and supported readable capture format first; TIME has indexed catalogue evidence, Economist only provider evidence, Statesman/Prospect unresolved.
  7. Use exact publisher+headline+date first; fuzzy variants return candidates for review and reject ties, wrong source, wrong date and unsafe URLs. Expand tests for very short headlines, accented titles and ambiguous editions.
