# Architecture

The app is a Vinext/Next-style Worker backed by Cloudflare D1. `app/` holds routes; `lib/` holds source retrieval, capture rendering, auth, room access, discussion and AI-bound evidence checks. `db/schema.ts` and numbered `drizzle/` SQL files define the persistent model. `public/` holds app icons and service-worker assets. `extension-library/` is optional browser-extension source for a user-initiated capture or authorised library workflow. `server-library/handler.mjs` is an optional AWS Lambda handler reference; deployment configuration is deliberately absent.

Room membership and selected room are server-validated. `rr_rooms`, `rr_room_members` and `rr_room_articles` map people and articles to rooms. `rr_room_comments` binds every post and parent to a room, article and authenticated member. The API rechecks membership and article access for reads and writes, then checks reply parents in the same room and article. Approval mode limits visibility of pending posts; hiding a parent hides its thread from ordinary members. Client text is rendered through DOM text nodes.

Captured source material is stored as a private edition and rendered with source attribution. AI commentary is kept in separate collapsed controls. Public search and index metadata do not establish full-text access. Legacy share-link endpoints are separate from the private room model and should remain closed unless the operator intentionally supports them with equivalent access controls.

Provider keys and library credentials belong in server-side secret storage. The browser never needs the AI key. An optional library connector or Lambda can access only a provider session the operator is authorised to use; this source package has no such session. The live deployment must provide HTTPS, identity headers, database bindings, rate limits, backups, and a review of the host's storage and retention rules. Local preview credentials and simulated sign-in do not establish production safety.

The bundled `npm test` selection exercises synthetic owner bootstrap, room access, article isolation, discussion visibility, shell behavior, and service-worker privacy. Build and type-check with `npm run build` and `npx tsc --noEmit --incremental false`. The upstream lint configuration currently reports existing `any`-type violations, so a clean lint result is not claimed for this package. A passing build is not a licence check or proof that a publisher's page is complete. Validate reading and installation on the intended physical phone before claiming those experiences work there.
