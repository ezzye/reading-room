Capture visible media from Chrome

Download Page Lens extension

Use Page Lens in Chrome to enable one source tab for ten minutes. Keep that newspaper tab active and its window focused. You can then request its visible images and player references from this room on your phone.

Permission and limits

No navigation, scrolling, hidden frames, source text, library card or browser cookies are requested. One enabled tab, ten minutes, visible-media references only. Review extension permissions before loading or running an update.

Start with “Enable this tab” in the Page Lens popup. Return to the source tab yourself after connecting.

Nothing is captured until you enable a tab and request it.

Source fidelity and import

Media only. Original positions and playback are not verified. Import appends safe references to one exact matching article already saved in this room; its text and commentary stay unchanged.
