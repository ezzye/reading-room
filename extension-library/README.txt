RET Camden Connector 0.2.0 — private study group

Update the already installed connector by reloading it in Chrome’s Extensions page. The host permissions are unchanged. Existing pairing is retained. Do not paste the old one-time pairing code again.

Keep Chrome running on the awake Mac, Camden NewsBank signed in, and RET /library-connector signed in as the owner. The connector uses a fixed same-origin request in Chrome’s isolated extension world on the RET tab. It does not read, export or store cookies; no hosting service bypass key is bundled. The server additionally requires the owner session and the revocable connector token. The daughter’s account can request an edition, but cannot operate the owner connector.

On an unavailable Times URL import, RET queues the request. The connector checks once a minute, reads the ordinary Times headline, searches Camden’s Times collection, and accepts only one sufficiently close headline match. It sends the bounded library text to private RET and DeepSeek. RET retains the supplied paragraphs in order and adds separate, collapsed commentary. AI does not rewrite the article.

If the same publisher page is readable and its captured paragraphs cover every supplied library paragraph in order, RET can retain that observed styling and media. Otherwise it retains all supplied library paragraphs in a clearly identified approximate newspaper layout. NewsBank text alone cannot supply original Times fonts, page geometry, photographs or video. No missing media or their positions are invented. Completeness always needs comparison with the original.

Permissions: alarms, storage, scripting, and host access only to thetimes.com, infoweb.newsbank.com, dayofflondon.com and the existing RET Sites address. No cookies, password, history, all-sites or debugger permissions. Temporary newspaper/library tabs close after each lookup; the RET owner tab remains open. Pairing expires after 30 days; pause in the popup or revoke in RET. Original article text and annotations are retained in the private RET database until removed; sharing links last seven days, with fifteen new links per page per UTC day. Downloaded HTML files are independent copies.

The Mac being asleep, Chrome closed, an expired library/RET login, ambiguous headlines or missing library records prevent automatic delivery. The connector reports these states rather than inventing a result.

Verification is described in the accompanying RET status page. Local tests, hosting deployment and a live two-phone test are distinct checks. This prototype does not assert provider endorsement or a determination about any particular use.
